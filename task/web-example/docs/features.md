# Vivant Gastronomy Features

This document outlines the features of the Vivant Gastronomy application.

## Core Features

- **Point of Interest (POI) Search:** The primary feature of the application is to search for POIs such as restaurants, bars, and other establishments. The search functionality is powered by Google Maps and Places APIs.
- **Map View:** Search results are displayed on an interactive map, allowing users to visualize the location of each POI.
- **Fine-Grained Search Filters:** Users can apply a variety of filters to their searches to narrow down the results. These filters provide more specific options than the standard Google Maps search.
- **Saved Places:** Users can save their favorite POIs to a personal list for future reference.
- **User Authentication:** The application supports user authentication, allowing users to have personalized experiences and save their data.

## Additional Features

- **Responsive Design:** The application is designed to be used on both desktop and mobile devices.
- **Add to List:** Users can add a POI to a custom list.
- **Debug Overlay:** A debug overlay is available to help with development and troubleshooting.
- **User Profile:** Authenticated users have a profile where they can manage their saved places and lists.
